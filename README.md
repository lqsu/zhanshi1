# 作品集网站 / Portfolio Website

这是一个用于展示网页设计与前端开发作品的静态作品集网站。

首页采用卡片式布局展示不同项目，每个卡片对应一个网站案例，并支持在卡片内部轮播显示该项目的多张页面截图。适合用于个人作品集展示、客户案例演示、GitHub Pages 发布，以及后续扩展为更完整的案例展示系统。

---

## 项目特点

- 首页卡片式布局，适合作品集展示
- 每个卡片可展示一个项目的多张页面截图
- 支持卡片内图片轮播切换
- 页面结构清晰，便于维护和扩展
- CSS 与 JavaScript 已从 `index.html` 中拆分到独立目录
- 可作为静态网站直接部署到 GitHub Pages
- 适合作为后续案例库、展示站、模板项目的基础版本

---

## 适用场景

本项目适合以下用途：

- 个人前端作品集网站
- 网页设计案例展示页

## 技术栈

本项目当前使用的技术栈如下：

### HTML5
用于页面结构搭建与内容组织。

### CSS3
用于页面布局、视觉样式、响应式适配、卡片展示效果等。

### JavaScript（原生 JS）
用于项目卡片渲染、图片轮播逻辑、交互控制等功能。

### Swiper（如当前项目已接入）
用于实现每个卡片中的多图轮播效果。

## 页面说明

### 首页展示逻辑

首页以项目卡片列表的形式展示不同网站案例。

每个项目卡片通常包含以下内容：

- 项目标题
- 项目简介
- 项目缩略信息
- 多张页面截图轮播
- 跳转按钮或预留操作区域（如需要）

### 图片轮播逻辑

每个卡片都可以绑定属于自己的图片列表，用于展示该项目的多个页面截图，例如：

- 首页
- 产品页
- 列表页
- 详情页
- 联系页
- 移动端页面

这种方式比单张展示更适合作品集项目，可以更完整地体现一个网站项目的页面结构与设计风格。

## 如何新增项目

后续如需新增一个作品项目，通常只需要以下几步：

### 1）新增项目截图目录

例如新增一个 `project05`：

```bash
images/project05/
├─ 1.webp
├─ 2.webp
└─ 3.webp
```

### 2）在 JS 配置中新增项目数据

在 `js/main.js` 中添加新的项目对象，例如：

```js
{
  title: '项目标题',
  description: '这里填写项目简介',
  images: [
    'images/project05/1.webp',
    'images/project05/2.webp',
    'images/project05/3.webp'
  ]
}
```

### 3）页面自动渲染

如果当前项目采用的是数据驱动渲染方式，那么新增配置后即可自动生成新的项目卡片。

## 如何修改样式

## 部署方式

### 本地预览

直接用浏览器打开 `index.html` 即可预览。

如果涉及本地资源加载限制，建议使用本地服务器进行预览，例如 VS Code 的 Live Server。

### GitHub Pages 部署

你可以直接将本仓库上传到 GitHub，并开启 GitHub Pages 进行静态网站托管。

常见步骤如下：

1. 将项目推送到 GitHub 仓库
2. 进入仓库设置 `Settings`
3. 找到 `Pages`
4. 选择部署分支（如 `main`）
5. 设置根目录（通常为 `/root`）
6. 保存后即可获得在线访问地址

## 维护建议

为了方便后续长期使用，建议遵循以下维护方式：

- 图片资源统一放在 `images/` 目录
- 样式统一维护在 `css/` 目录
- 脚本统一维护在 `js/` 目录
- 项目数据尽量采用配置化写法
- 每新增一个项目，尽量保持统一的目录和命名规范

这样后续不管是扩展作品数量，还是改造成其他展示用途，都会更高效。
